Validar XML da nota

Confira se o XML da NF-e, NFC-e, NFS-e ou CT-e segue o leiaute oficial com os grupos de IBS, CBS e IS, usando os mesmos XSD da calculadora oficial.

ou cole o XML

O XML é enviado só para validação e não é guardado. A validação confere a estrutura e os formatos (XSD); não confere se os valores calculados estão certos — para isso, use o simulador.
